ระบบบริหารจัดการบัญชีผู้ใช้งาน (Bank Officer Management)

สร้าง กำหนดสิทธิ์ และควบคุมการเข้าถึงระบบวิเคราะห์เส้นทางการเงินสำหรับเจ้าหน้าที่ธนาคาร (Role: user) ความปลอดภัยตามมาตรฐานความมั่นคงปลอดภัยสารสนเทศและการแบ่งแยกบทบาทหน้าที่ (RBAC)

เจ้าหน้าที่ธนาคารทั้งหมด 0 บัญชีที่ลงทะเบียนในระบบ (role=user)
เปิดใช้งานปกติ (Active) 0 สามารถเข้าสู่ระบบสืบสวนคดีได้
ถูกระงับการใช้งาน (Disabled) 0 เซสชันถูกยกเลิกและห้ามเข้าสู่ระบบ

บัญชีผู้ดูแลระบบ (Administrator Accounts)

🛡️ สิทธิ์ระดับระบบ (Protected System Accounts)

บัญชีระดับผู้ดูแลระบบสำหรับบริหารจัดการโครงสร้างและนโยบายความปลอดภัย — สงวนสิทธิ์เฉพาะ และไม่สามารถแก้ไขหรือระงับผ่านส่วนติดต่อนี้ได้

ชื่อผู้ดูแลระบบ (Display Name) อีเมลองค์กร (Email) บทบาท (Role) สถานะ (Status) วันที่สร้าง (Created At) ระดับการควบคุม (Protection)

บัญชีเจ้าหน้าที่ธนาคาร (Bank Officer Accounts)

จัดการการเปิด/ปิดบัญชี การรีเซ็ตรหัสผ่าน และการตรวจสอบการเข้าใช้งานสำหรับเจ้าหน้าที่สืบสวนคดี

ชื่อเจ้าหน้าที่ (Display Name) อีเมลองค์กร (Email) บทบาท (Role) สถานะ (Status) วันที่สร้าง (Created At) เข้าสู่ระบบล่าสุด (Last Login) การจัดการ (Actions)

ชื่อสำหรับแสดงผลในบันทึกการสืบสวนและประวัติการทำงาน
ใช้เป็นชื่อผู้ใช้ในการเข้าสู่ระบบ ต้องไม่ซ้ำกับบัญชีที่มีอยู่เดิม
นโยบายความปลอดภัยรหัสผ่าน (Password Policy):
  • • ความยาวอย่างน้อย 10 ตัวอักษร
  • • ตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก (A-Z, a-z)
  • • ตัวเลขอย่างน้อย 1 ตัว (0-9)
  • • อักขระพิเศษ (!@#$%^&*...)
🔒 หมายเหตุความปลอดภัย: บัญชีนี้จะได้รับบทบาท Bank Officer (role: user) โดยอัตโนมัติ และจะสามารถเข้าถึงเฉพาะระบบสืบสวนคดีทางการเงินเท่านั้น (ไม่สามารถเข้าสู่ Admin Portal ได้)
